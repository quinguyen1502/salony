# Desktop

macOS and Windows run the full front desk, in the tablet layout: Home's
shortcut tiles open the same screens as the phone. Staff get the phone
layout in a centred column.

## Overview

The PC joins the salon as its own device and syncs like a phone.

## Usage

A desktop can **start** pairing. On the new device, open **Settings →
Join a store** and keep it on this Wi-Fi. On the PC: **Settings → Add
another device** (or **Staff → Add staff → Invite staff**), tap the name
under **Nearby devices**, confirm the six-digit code on both screens,
then send. No camera.

The PC also **shows a QR** on the Join a store screen, so a phone can scan
this machine. **Scan the other device** / **Scan QR** are hidden on Mac
and Windows.

If **Nearby devices** stays empty, see
[The other device does not show up](devices.md#not-found): a phone scans the
QR instead, because the PC cannot. If this PC is the *only* device, create the
store here.

Invite as **Manager**; promote to Owner only with a reason. On Windows, each
Windows account on the PC has its own Salony, so always sign in to Windows as
the same user.

**Printing.** A desktop prints straight to a thermal printer on the salon
network, the same as a phone does: **Settings → Thermal printer**. Bluetooth
printers are the exception — those pair from phones and tablets only. A printer
on USB goes through the system print dialog, which still works for every kind
of printer. See [Thermal printers](../guide/printers.md).

## Limitations

In **Protect your salon**, two options are left out on purpose:

1. **Show recovery key (24 words)**: it paints the words on screen, which a
   computer cannot hide from screen capture. Save the recovery key as a
   **Recovery key file** instead.
2. **Move to a new device**: needs a camera. To replace a PC, add the new one
   with **Add another device**.

Still there: the recovery key file (with its own password) and the salon
backup.

If the PC is the only device, keep both files **off** that PC. To restore,
install again and use **Restore your salon on this device**.

No phone-style home-screen widget. No pairing a Bluetooth printer.
