# Quản trị

Cài đặt tiệm, sao lưu, đồng bộ. Phần kiến trúc dành cho người muốn biết dữ
liệu nằm ở đâu.

## Tổng quan

**Vận hành** là việc chủ/quản lý làm trên máy. **Kiến trúc** giải thích
local-first, identity, event, sync. Việc hàng ngày nằm ở
[Hướng dẫn](../guide/index.md).
