# Bắt đầu

Cài app, tạo danh tính trên máy, mở tiệm, rồi chuẩn bị vài việc trước khi
đón khách.

## Tổng quan

Không cần tài khoản đăng nhập. Mỗi máy có **identity** riêng. Tiệm chạy trên
máy, nên mất mạng vẫn đặt lịch và lập hóa đơn được.
