# Getting started

Open the app for the first time, create or join a store, then do a few things
before you take customers.

## Overview

No login account is required. The salon runs on the device, so bookings and
bills still work offline. A recovery key and a salon backup are what bring it
back if the device is lost.

## Usage

1. [First launch](first-launch.md) — set up this device, your name, crash reports
2. [Create or join a store](store.md)
3. [First day](first-day.md) — protect your salon, staff, services

Need a build: [Downloads](../admin/downloads.md).
